# App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace default Flutter icons with custom Lorebase app icon for Android and web.

**Architecture:** Crop the AI-generated LorebaseIcon.jpeg to a square, convert to PNG, then use `flutter_launcher_icons` for Android adaptive icons and a Python script for web icons. No code changes needed in the Dart app itself.

**Tech Stack:** Flutter 3.27, flutter_launcher_icons ^0.14.1, Python 3 + Pillow

### Task 1: Stage and crop source image

**Files:**
- Create: `assets/app_icon.png`
- Source: `~/Downloads/LorebaseIcon.jpeg`

- [ ] **Step 1: Add `assets/` to pubspec.yaml and create directory**

Edit `pubspec.yaml`:
```yaml
flutter:
  uses-material-design: true
  assets:
    - .env
    - assets/
```

Create directory:
```bash
mkdir -p assets
```

- [ ] **Step 2: Crop center 816×816 from source and save as PNG**

```bash
python3 -c "
from PIL import Image
img = Image.open('$HOME/Downloads/LorebaseIcon.jpeg')
w, h = img.size
size = min(w, h)
left = (w - size) // 2
top = (h - size) // 2
cropped = img.crop((left, top, left + size, top + size))
cropped.save('assets/app_icon.png')
print(f'Saved assets/app_icon.png ({size}x{size})')
"
```

Expected output: `Saved assets/app_icon.png (816x816)`

- [ ] **Step 3: Commit staged source**

```bash
git add assets/app_icon.png pubspec.yaml
git commit -m "chore: add cropped source icon to assets/"
```

### Task 3: Generate web icons

**Files:**
- Replace: `web/favicon.png`
- Replace: `web/icons/Icon-192.png`
- Replace: `web/icons/Icon-512.png`
- Replace: `web/icons/Icon-maskable-192.png`
- Replace: `web/icons/Icon-maskable-512.png`

- [ ] **Step 1: Run generation script**

```bash
python3 -c "
from PIL import Image
import os

src = Image.open('assets/app_icon.png')

sizes = {
    'web/favicon.png': 32,
    'web/icons/Icon-192.png': 192,
    'web/icons/Icon-512.png': 512,
}

for path, size in sizes.items():
    resized = src.resize((size, size), Image.LANCZOS)
    resized.save(path)
    print(f'Generated {path} ({size}x{size})')

# Maskable: scale to 80% and center on white bg (safety zone)
for base_name, size in [('Icon-maskable-192.png', 192), ('Icon-maskable-512.png', 512)]:
    path = f'web/icons/{base_name}'
    canvas = Image.new('RGB', (size, size), (255, 255, 255))
    inner_size = int(size * 0.8)
    resized = src.resize((inner_size, inner_size), Image.LANCZOS)
    offset = (size - inner_size) // 2
    canvas.paste(resized, (offset, offset))
    canvas.save(path)
    print(f'Generated {path} ({size}x{size}, maskable)')
"
```

Expected: 5 PNG files written, no errors.

- [ ] **Step 2: Verify web icons**

```bash
ls -la web/favicon.png web/icons/
```

Expected: 5 files with reasonable sizes (not 0 bytes).

- [ ] **Step 3: Commit**

```bash

git commit -m "feat: add web app icons (favicon + PWA manifest)"
```
