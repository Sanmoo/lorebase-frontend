# Real Follow Users Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render real enriched BFF users in Followers and Following, and navigate each row to the public profile.

**Architecture:** Replace the old follow relationship DTO fields with the BFF `FollowItem` fields and update both follow-list UIs to render the enriched user. Keep repository endpoints and viewmodel selection unchanged; only the item shape and row rendering change.

**Tech Stack:** Flutter 3.27, Dart, Riverpod codegen, Freezed/json_serializable, GoRouter, flutter_test.
