# Frontend i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add internationalization support (pt-BR, en-US, es) using slang + Riverpod, including UI string externalization, Accept-Language header, locale detection, and language switcher.

**Architecture:** slang generates type-safe Translations from JSON files via build_runner. A localeProvider reads system locale with user-override persistence. Dio interceptor injects Accept-Language header. All pages replace hardcoded strings with `context.t.chave`.

**Tech Stack:** Flutter, Dart, slang v4, slang_flutter, flutter_localizations, Riverpod, Dio

```dart
import 'dart:ui';

import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:flutter_secure_storage/flutter_secure_storage.dart';

const _localeStorageKey = 'locale';

final localeProvider = NotifierProvider<LocaleNotifier, Locale>(
  LocaleNotifier.new,
);

class LocaleNotifier extends Notifier<Locale> {
  @override
  Locale build() {
    _loadSavedLocale();
    return _localeFromPlatform();
  }

  Future<void> _loadSavedLocale() async {
    try {
      final storage = ref.read(secureStorageProvider);
      final saved = await storage.read(key: _localeStorageKey);
      if (saved != null) {
        final parts = saved.split('_');
        if (parts.length == 2) {
          state = Locale(parts[0], parts[1]);
        } else {
          state = Locale(parts[0]);
        }
      }
    } catch (_) {}
  }

  Locale _localeFromPlatform() {
    final deviceLocale = PlatformDispatcher.instance.locale;
    const supported = [
      Locale('pt', 'BR'),
      Locale('en', 'US'),
      Locale('es'),
    ];
    for (final locale in supported) {
      if (locale.languageCode == deviceLocale.languageCode) {
        return locale;
      }
    }
    return const Locale('pt', 'BR');
  }

  Future<void> setLocale(Locale locale) async {
    state = locale;
    try {
      final storage = ref.read(secureStorageProvider);
      final value = locale.countryCode != null
          ? '${locale.languageCode}_${locale.countryCode}'
          : locale.languageCode;
      await storage.write(key: _localeStorageKey, value: value);
    } catch (_) {}
  }
}

final secureStorageProvider = Provider<FlutterSecureStorage>((ref) {
  return const FlutterSecureStorage();
});
```

### Task 4: Create LocaleInterceptor

- [ ] **Step 1: Create the interceptor**

```dart
import 'package:dio/dio.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../i18n/locale_provider.dart';

class LocaleInterceptor extends Interceptor {
  final Ref _ref;

  LocaleInterceptor(this._ref);

  @override
  void onRequest(
    RequestOptions options,
    RequestInterceptorHandler handler,
  ) {
    final locale = _ref.read(localeProvider);
    options.headers['Accept-Language'] = locale.toLanguageTag();
    handler.next(options);
  }
}
```

```dart
        );
        break;
      case DioExceptionType.badResponse:
        final statusCode = err.response?.statusCode;
        if (statusCode == 401) {
          err = err.copyWith(
            error: const AuthException(message: 'Session expired. Please log in again.'),
          );
        } else if (statusCode != null && statusCode >= 500) {
          err = err.copyWith(
            error: const ServerException(message: 'Server error. Please try again later.'),
          );
        } else if (statusCode == 404) {
          err = err.copyWith(
            error: const ServerException(message: 'Resource not found.', statusCode: 404),
          );
        }
        break;
      default:
        err = err.copyWith(
          error: const NetworkException(message: 'Network error. Check your connection.'),
        );
    }
    handler.next(err);
  }
}
```

Note: The ErrorInterceptor currently doesn't have access to translations because it operates at the Dio level (no widget context). The error messages remain in English for now — they are technical/fallback messages. The UI layer (pages) catches these exceptions and can display them with localized strings if needed in the future.
