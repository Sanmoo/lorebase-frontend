# Social Activity Empty Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Diagnose and fix Social activity tabs that appear empty despite real activity data, while creating backend backlog items if the real API is the source of the issue.

**Architecture:** Validate the real backend contract first via direct API calls, then validate the browser/UI flow against the same backend. Fix frontend behavior with TDD by normalizing activity payloads when appropriate and by distinguishing activity-load failures from true empty activity lists.

**Tech Stack:** Flutter 3.27, Dart, Riverpod codegen, Dio, Cognito token helper script, Flutter widget tests, Playwright MCP, WorkQ CLI.

- [ ] **Step 3: Query direct API endpoints and save sanitized evidence**

Run:

```bash
API_BASE="$(python - <<'PY'
from pathlib import Path
for line in Path('.env').read_text().splitlines():
    if line.startswith('API_BASE_URL='):
        print(line.split('=', 1)[1].strip())
PY
)"
python - <<'PY' "$API_BASE" "$ACCESS_JWT"
import json
import sys
from urllib.parse import urljoin
import urllib.request

base_url = sys.argv[1].rstrip('/')
jwt_value = sys.argv[2]
headers = {'Authorization': f'Bearer {jwt_value}'}
paths = ['/users/me/profile', '/feed?limit=20']
summary = []

def request(path):
    req = urllib.request.Request(base_url + path, headers=headers)
    try:
        with urllib.request.urlopen(req, timeout=20) as res:
            body = res.read().decode('utf-8')
            data = json.loads(body) if body else None
            return res.status, data
    except urllib.error.HTTPError as exc:
        body = exc.read().decode('utf-8')
        try:
            data = json.loads(body) if body else None
        except json.JSONDecodeError:
            data = {'raw': body[:200]}
        return exc.code, data

status, profile = request('/users/me/profile')
summary.append({'path': '/users/me/profile', 'status': status, 'keys': sorted(profile.keys()) if isinstance(profile, dict) else None})
if isinstance(profile, dict) and profile.get('userId'):
    paths.append(f"/profiles/{profile['userId']}/activity?limit=20")

for path in paths[1:]:
    status, data = request(path)
    items = data.get('items') if isinstance(data, dict) else None
    first = items[0] if isinstance(items, list) and items else None
    summary.append({
        'path': path,
        'status': status,
        'itemCount': len(items) if isinstance(items, list) else None,
        'topLevelKeys': sorted(data.keys()) if isinstance(data, dict) else None,
        'firstItemKeys': sorted(first.keys()) if isinstance(first, dict) else None,
        'firstItemPreview': {k: first.get(k) for k in sorted(first.keys()) if k in {'eventId', 'id', 'activityType', 'type', 'user', 'media', 'createdAt', 'timestamp', 'metadata'}} if isinstance(first, dict) else None,
    })

print(json.dumps(summary, indent=2, ensure_ascii=False))
PY
```

Expected: sanitized JSON with paths, statuses, item counts, and field names only. No Authorization header or token appears.
