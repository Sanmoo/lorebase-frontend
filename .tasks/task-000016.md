## Problema

Na página **Social**, o usuário `sanmoo.cs` não consegue visualizar a lista completa de itens em algumas seções.

Um exemplo observado é a seção **Quero Ver**: o usuário vê apenas **1 filme**, quando deveria ver pelo menos **2 itens**.

Ainda não está claro se a causa está no frontend ou no backend. Caso a investigação indique que o backend está retornando dados incompletos/incorretos, será necessário coletar evidências suficientes para abrir uma issue no repositório `lorebase-backend`.

## Comportamento esperado

Na página **Social**, as listas públicas do usuário devem exibir todos os itens disponíveis/esperados para cada seção, respeitando as regras de privacidade e paginação.

Para o usuário `sanmoo.cs`, a seção **Quero Ver** deve exibir pelo menos os itens esperados atualmente, incluindo mais de um filme quando houver mais de um item disponível.

## Critérios de aceite

- [ ] Reproduzir o problema na página **Social** para o usuário `sanmoo.cs`.
- [ ] Verificar a seção **Quero Ver** e confirmar por que apenas 1 filme aparece.
- [ ] Confirmar se o frontend está filtrando, truncando, paginando ou sobrescrevendo itens indevidamente.
- [ ] Confirmar se a API/backend está retornando a lista completa esperada.
- [ ] Se o problema estiver no frontend, corrigir a exibição para mostrar todos os itens esperados.
- [ ] Se o problema estiver no backend, coletar evidências objetivas para abertura de issue em `lorebase-backend`, incluindo endpoint(s), payload(s), resposta(s) e comportamento esperado.
- [ ] Garantir que estados de carregamento, erro e lista vazia continuem funcionando corretamente.
