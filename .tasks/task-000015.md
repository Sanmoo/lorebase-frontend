## Problema

A seleção feita pelo usuário no filtro de tipo de mídia (**Séries / Filmes**) não está sendo persistida entre telas.

Atualmente, sempre que o usuário muda de tela que possui esse filtro, a seleção volta para **Séries**, mesmo que ele tenha selecionado **Filmes** anteriormente.

## Comportamento esperado

A escolha do usuário no filtro de mídia deve ser mantida ao navegar entre telas que usam esse filtro.

Se o usuário selecionar **Filmes**, as próximas telas com filtro de mídia devem abrir mantendo **Filmes** selecionado. O mesmo deve valer para **Séries**.

## Critérios de aceite

- [ ] Ao selecionar **Filmes** no filtro de mídia, a seleção permanece ao mudar para outra tela com o mesmo filtro.
- [ ] Ao selecionar **Séries** no filtro de mídia, a seleção permanece ao mudar para outra tela com o mesmo filtro.
- [ ] O filtro não volta automaticamente para **Séries** durante a navegação.
- [ ] A seleção persistida é usada para carregar/exibir os dados corretos da tela atual.
- [ ] O comportamento funciona nas telas existentes que possuem filtro **Séries / Filmes**.
