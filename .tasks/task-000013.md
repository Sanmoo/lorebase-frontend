## Problema

As abas **Followers** e **Following** na área Social mostram apenas um item genérico com o nome **Usuário**, em vez de listar os perfis reais.

Além disso, os itens exibidos não permitem navegar para o perfil público dessas pessoas.

## Comportamento esperado

Na área Social:

- a aba **Followers** deve listar os usuários que seguem o perfil;
- a aba **Following** deve listar os usuários que o perfil está seguindo;
- cada item deve exibir informações reais do usuário, como nome de exibição e/ou identificador;
- ao clicar em um usuário da lista, o app deve abrir o perfil público dessa pessoa;
- o perfil público deve permitir visualizar as informações públicas disponíveis, incluindo listas de atividades.

## Critérios de aceite

- [ ] A aba **Followers** deixa de exibir o item genérico **Usuário**.
- [ ] A aba **Followers** exibe a lista real de seguidores.
- [ ] A aba **Following** deixa de exibir o item genérico **Usuário**.
- [ ] A aba **Following** exibe a lista real de usuários seguidos.
- [ ] Cada item da lista mostra dados reais do usuário.
- [ ] Tocar em um usuário abre o perfil público correspondente.
- [ ] O perfil público exibe as informações públicas disponíveis, incluindo listas de atividades.
- [ ] Estados de carregamento, erro e lista vazia são tratados nas duas abas.
