## Problema

Na aba Social, ao clicar no botão **"Seguir"**, nada acontece.

## Comportamento atual

- O usuário acessa a aba Social.
- Clica no botão **"Seguir"** em outro usuário/perfil.
- Nenhuma ação visível ocorre.
- Não há feedback de carregamento, sucesso ou erro.

## Comportamento esperado

- Ao clicar em **"Seguir"**, o app deve executar a ação de seguir o usuário/perfil selecionado.
- A UI deve refletir o novo estado, por exemplo:
  - botão muda para **"Seguindo"** ou equivalente;
  - contador/lista de seguidores é atualizado, se aplicável;
  - erro é exibido caso a operação falhe.

## Critérios de aceite

- [ ] O botão **"Seguir"** dispara a chamada/ação correta.
- [ ] O estado visual muda após sucesso.
- [ ] O usuário recebe feedback em caso de falha.
- [ ] A ação não fica silenciosamente sem efeito.
- [ ] Testes cobrem o fluxo de clique no botão **"Seguir"**.

## Observações

Investigar se o problema está na ausência de handler no botão, falha silenciosa na viewmodel/repository, integração incompleta com API ou falta de atualização de estado na UI.
