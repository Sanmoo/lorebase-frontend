## Problema

Ao tentar seguir um usuário, a interface exibe a mensagem de erro:

> Não foi possível seguir esse usuário.

Precisamos investigar se a falha está no frontend, na integração com a API ou no backend.

## Objetivo

Corrigir o fluxo de seguir usuário ou, caso o problema esteja no backend, coletar evidências suficientes para encaminhar ao time responsável.

## Escopo

- Reproduzir o erro ao seguir um usuário.
- Identificar a chamada de API feita pelo frontend nesse fluxo.
- Verificar payload, headers, status code e resposta da API.
- Confirmar se o frontend está enviando os dados esperados.
- Corrigir o frontend caso o problema esteja na aplicação.
- Caso o problema esteja no backend, documentar evidências técnicas.

## Critérios de aceite

- O usuário consegue seguir outro usuário sem erro quando a API responde com sucesso.
- Em caso de falha de frontend, o bug é corrigido e coberto por teste quando aplicável.
- Em caso de falha de backend, deve ser entregue evidência contendo:
  - endpoint chamado;
  - método HTTP;
  - payload enviado;
  - status code retornado;
  - corpo da resposta;
  - headers relevantes, sem expor tokens ou segredos;
  - passos para reprodução;
  - usuário/origem e usuário/destino usados no teste, se seguro compartilhar.

## Observações

Se for confirmado que o erro vem do backend, não implementar workaround silencioso no frontend sem alinhamento. Apenas melhorar a mensagem de erro se fizer sentido e registrar claramente a causa provável.
