## Objetivo

Investigar quais dados adicionais o backend já retorna para séries e filmes, mas que ainda não são exibidos no frontend, e propor melhorias nas telas de detalhes para aproveitar essas informações.

## Contexto

Há indícios de que a API do backend retorna mais campos para séries e filmes do que os atualmente apresentados nas respectivas telas de detalhes. Antes de implementar mudanças visuais, precisamos mapear esses dados disponíveis e decidir quais agregam valor para o usuário.

## Escopo

- Verificar nas respostas da API do backend quais campos estão disponíveis para:
  - detalhes de séries;
  - detalhes de filmes.
- Comparar os campos retornados com o que o frontend exibe atualmente.
- Identificar dados úteis que ainda não aparecem na UI.
- Propor opções de design para exibir as novas informações nas telas de detalhes.
- Considerar alternativas de layout, agrupamento e priorização visual das informações.
- Documentar uma recomendação de abordagem antes da implementação.

## Critérios de aceite

- Existe um levantamento dos campos retornados pela API para séries e filmes.
- Existe uma comparação clara entre dados disponíveis no backend e dados exibidos no frontend.
- Foram identificadas oportunidades concretas de melhoria nas telas de detalhes.
- Foram propostas pelo menos 2 opções de design/layout para apresentar as informações adicionais.
- Há uma recomendação final indicando quais dados devem ser exibidos e como.
- Nenhuma mudança de UI é implementada sem validação prévia da proposta.

## Observações

O design está em aberto. Podemos considerar novas seções, cards informativos, agrupamentos por tema, expansão progressiva de detalhes, ou outras abordagens que façam sentido para melhorar a experiência sem poluir a tela.
