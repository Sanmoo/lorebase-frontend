## Problema

O dashboard do usuário `sanmoo.cs@gmail.com`, que possui muitas séries completadas, às vezes carrega a lista de séries completadas como vazia, indicando zero itens. Ao atualizar o dashboard uma ou mais vezes, o valor correto volta a aparecer.

## Impacto

Usuários com muitas séries completadas podem receber uma visão incorreta do próprio progresso/listas no dashboard, reduzindo confiança nos dados exibidos.

## Evidências / Contexto

- Usuário afetado conhecido: `sanmoo.cs@gmail.com`
- O problema parece intermitente.
- O refresh do dashboard geralmente restaura os dados corretos.
- A ocorrência pode estar relacionada a volume alto de séries completadas, carregamento assíncrono, paginação, cache, race condition ou resposta parcial da API.

## Objetivo

Investigar e corrigir a causa da intermitência no carregamento das séries completadas no dashboard, garantindo que a lista e o contador reflitam corretamente os dados do backend.

## Escopo sugerido

- Reproduzir o problema com o usuário afetado ou dados equivalentes.
- Verificar chamadas de API feitas pelo dashboard ao carregar séries completadas.
- Inspecionar tratamento de estados de loading, erro, empty state e refresh.
- Verificar se há paginação, limite, timeout, cache ou race condition causando estado vazio incorreto.
- Adicionar ou ajustar testes para cobrir o cenário em que muitas séries completadas são retornadas.

## Critérios de aceite

- O dashboard não deve exibir zero séries completadas quando a API/backend possui séries completadas para o usuário.
- Estados vazios devem ser exibidos apenas quando a resposta válida confirmar ausência de séries completadas.
- Refreshs repetidos não devem ser necessários para corrigir o estado exibido.
- Erros/intermitências de API devem ser tratados de forma visível ou recuperável, sem sobrescrever dados válidos com lista vazia indevidamente.
- Testes relevantes devem cobrir o comportamento corrigido.
