## Problema

Na aba **Social**, a subaba **Atividade** aparece sempre vazia.

Isso ocorre tanto para o usuário logado quanto ao visualizar perfis de seguidores.

## Comportamento observado

- Ao acessar **Social > Atividade**, nenhuma atividade é exibida.
- A lista permanece vazia mesmo quando deveria haver atividade recente.
- O problema também acontece ao abrir o perfil de seguidores e tentar visualizar a atividade deles.

## Comportamento esperado

- A aba **Atividade** deve exibir as atividades recentes do usuário logado.
- Ao visualizar o perfil de um seguidor, a aba **Atividade** deve exibir as atividades públicas ou permitidas daquele perfil.
- Caso realmente não existam atividades, a interface deve diferenciar claramente estado vazio real de falha/carregamento.

## Critérios de aceite

- Investigar por que **Social > Atividade** está sempre vazia.
- Verificar se o frontend está chamando o endpoint correto para:
  - atividade do usuário logado;
  - atividade de perfis de seguidores.
- Verificar se filtros, paginação, autenticação ou parsing da resposta estão descartando atividades válidas.
- Corrigir a exibição da lista de atividades quando houver dados disponíveis.
- Garantir estado vazio apropriado quando não houver atividades reais.
- Adicionar ou ajustar testes cobrindo:
  - usuário logado com atividades;
  - usuário logado sem atividades;
  - perfil de seguidor com atividades visíveis;
  - perfil de seguidor sem atividades visíveis;
  - erro ou resposta inesperada da API.
