# Corrigir botão de seguir em perfil social

## Problema

Na aba Social, ao visitar a página de perfil de um usuário que eu sigo ou que me segue, o botão abaixo do avatar ainda exibe `Seguir`.

Quando eu já sigo esse usuário, o botão deveria exibir `Deixar de Seguir`.

## Comportamento esperado

- Ao abrir o perfil de um usuário que já sigo:
  - o botão abaixo do avatar deve mostrar `Deixar de Seguir`.
- Ao abrir o perfil de um usuário que ainda não sigo:
  - o botão deve continuar mostrando `Seguir`.

## Critérios de aceite

- [ ] O estado de relacionamento social do usuário visitado é carregado corretamente na página de perfil.
- [ ] O botão abaixo do avatar exibe `Deixar de Seguir` quando o usuário já é seguido.
- [ ] O botão exibe `Seguir` quando o usuário ainda não é seguido.
- [ ] A lógica funciona ao acessar perfis pela aba Social.
- [ ] Testes relevantes são adicionados ou atualizados.
