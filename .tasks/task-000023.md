## Objetivo

Adicionar ao app a capacidade de o usuário definir ou atualizar seu avatar, usando uma imagem escolhida da galeria ou uma foto tirada na hora.

## Contexto

A tarefa deve começar com uma seção de brainstorming para definir a melhor abordagem de implementação antes de alterar código.

Essa definição deve considerar os padrões existentes do app, limitações de Flutter web/mobile, integração com backend/API, autenticação, permissões de câmera/galeria e experiência de usuário.

## Escopo

- Conduzir brainstorming inicial para comparar abordagens possíveis de implementação.
- Definir onde o avatar será exibido e atualizado na interface existente.
- Permitir seleção de imagem da galeria.
- Permitir captura de foto pela câmera, quando suportado pela plataforma.
- Submeter o avatar para persistência no backend.
- Atualizar a interface após upload bem-sucedido.
- Tratar erros de permissão, cancelamento, arquivo inválido, falha de rede e falha de API.
- Manter compatibilidade com os padrões arquiteturais do projeto: feature structure, Riverpod, Dio, testes e navegação existente.

## Fora de escopo inicial

- Edição avançada de imagem, como crop, filtros ou rotação manual, salvo se o brainstorming concluir que um ajuste simples é indispensável.
- Múltiplos avatares por usuário.
- Galeria pública de avatares predefinidos.

## Critérios de aceite

- A tarefa documenta, antes da implementação, a abordagem escolhida e os trade-offs considerados.
- O usuário consegue escolher uma imagem da galeria para usar como avatar.
- O usuário consegue tirar uma foto na hora para usar como avatar, nas plataformas suportadas.
- O avatar é enviado para o backend usando autenticação adequada.
- A UI mostra estados claros de carregamento, sucesso e erro.
- Cancelar a seleção/captura não deve gerar erro visual indevido.
- Falhas de permissão, arquivo inválido, rede ou API devem ser comunicadas ao usuário.
- Após upload bem-sucedido, o novo avatar aparece na interface sem exigir logout/login.
- Testes são adicionados ou ajustados para cobrir:
  - seleção de imagem bem-sucedida;
  - captura de foto bem-sucedida, quando aplicável;
  - cancelamento pelo usuário;
  - erro de permissão;
  - falha no upload;
  - atualização do estado/UI após sucesso.
