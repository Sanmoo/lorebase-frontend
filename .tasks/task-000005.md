## Contexto
Ao clicar em um resultado de busca, o detalhe da série abriu, mas a URL permaneceu `/search`. A arquitetura documentada menciona rota protegida `/series/:tmdbId`.

## Resultado esperado
Se o detalhe for uma tela navegável, a URL deve refletir `/series/:tmdbId` para permitir deep link, refresh e compartilhamento.

## Sugestões
- Confirmar comportamento desejado de produto.
- Se aplicável, navegar com `context.go()` para `/series/:tmdbId`.
- Adicionar teste de navegação/deep link para detalhe de série.
